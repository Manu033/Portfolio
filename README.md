# Portfolio

En este repositorio voy a ir guardando mis **proyectos personales** y los que realicé en diferentes **cursos y capacitaciones**.  
El objetivo es mostrar mi progreso y aprendizaje en el desarrollo de software, así como tener una referencia centralizada de mis trabajos.

Aquí se incluyen prácticas y proyectos con distintas tecnologías, tanto de **frontend como backend**, además de ejercicios full-stack que combinan varias herramientas.
